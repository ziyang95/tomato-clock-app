# 番茄钟 iPhone 网页 App

## 本版更新
- 增加 Service Worker 自动更新检查：打开/恢复页面时检查新版本；新版本激活后自动刷新。
- 更新缓存版本，避免继续使用旧缓存。
- 尽量禁用 iPhone 长按文字选择、复制等系统菜单，并拦截网页的常见选择/剪贴板事件。
- 保留番茄计时、任务、统计、设置和本地数据功能。

## 部署
将解压后的全部文件上传到 GitHub Pages 仓库，替换同名文件并提交。部署成功后，联网重新打开网页测试。

## 说明
网页只能尽量阻止 iOS 长按菜单，无法保证所有 iOS 版本、所有系统界面都绝对禁用。自动更新需要联网并且 GitHub Pages 已完成部署。
